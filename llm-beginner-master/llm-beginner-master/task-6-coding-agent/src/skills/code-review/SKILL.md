# Code Review Skill

1. 明确改动意图：issue 要解决什么，补丁是否正中问题。
2. 对照测试：每一条测试断言是否都被满足，特别注意符号、边界、类型。
3. 检查无关改动：不要顺手重构、重命名、删测试。
4. 检查错误路径：异常、空输入、除零、越界。
5. 给出结论：APPROVE / NEEDS WORK + 具体位置与建议。

输出格式：

```
结论: APPROVE|NEEDS_WORK
风险点:
- ...
建议:
- ...
```
