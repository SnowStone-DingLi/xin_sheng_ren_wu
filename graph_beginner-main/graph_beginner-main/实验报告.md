# Graph Tasks 实验报告

## 1. 实验目的

按照 [readme.md](file:///readme.md) 的规定完成4个Graph任务（节点分类、链接预测、图分类、知识图谱），并记录实验现象。

## 2. 实验环境

- OS：Windows
- Python：3.8.13（conda env `pytorch`）
- torch：2.4.1+cu118（实际使用 CPU）
- torch-geometric：2.3.0


## 3. 各任务实验观察
### 任务一：节点分类
实验结果存放在task 1/results/task1_log.txt文件下。
1.Cora和Citeseer相对较小，训练开销小。相比之下，Flickr数据集较大，训练开销也大。
2.在不同模型中，GIN性能较差。其它模型性能相当。
3.采用采样子图匹配时，得到的模型性能不稳定，时而高于全图训练结果，时而低于全图训练结果。

### 任务二：链接预测
实验结果存放在task 2/results/task2_log.txt和task2_flickr_log.txt文件下。
1.链接预测任务普遍高于节点分类，任务难度相对较低。
2.仍然是GIN性能最差，GAT和GCN性能较优，GraphSAGE适中。

### 任务三：图分类
实验结果存放在task 3/results/task3_mutag_log.txt和task3_ZINC_log.txt文件下。
1.四种池化操作在不同模型上都有较优的时候。
2.层数过高并不会带来明显的性能收益。
3.之前表现较差的GIN，在图分类任务上性能还不错。
4.ZINC运行时间明显长于mutag。

### 任务四：知识图谱
实验结果存放在task 4/results/task4_log.txt文件下。
1.TransE开销最小，100个epochs耗时不超过10秒；RotatE开销适中，100个epochs耗时20~30秒；而ConvE开销最大，在我的设备上出现了OOM。
2.三者性能与开销大小基本呈现正比关系。
